# CoolCellCounterC

To compile the program you can use `./Compiler.sh`  

To compile and run the program on an easy, medium and hard image you can use `./CompileAndRun.sh`  

To time a part of or the whole program you can use `./CompileAndRun.sh [TIME_ALL | TIME_GRAY | TIME_BINARY | TIME_EROSION_SPOTS | TIME_MARKERS]`  
You can also just define one of these when compiling normally to time that part.
